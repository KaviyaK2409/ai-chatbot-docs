# AI Chatbot

## Introduction
The AI Chatbot is a web-based application that lets users type questions and get instant replies. It is built as a beginner-friendly project to show how a simple chat interface works and how it can be connected to an AI model in the future.

## Features
- Simple chat window for typing messages
- Instant replies to common questions
- Chat history shown on the screen
- Clear chat button to start a new conversation
- Works on both mobile and desktop screens

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation
1. Download the project from GitHub.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Usage
1. Open the chatbot page in your browser.
2. Type your question in the message box.
3. Click the **Send** button.
4. Read the reply shown in the chat window.
5. Click **Clear** to start a new chat.

## Future Enhancements
